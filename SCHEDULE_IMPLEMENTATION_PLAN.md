## 🏗️ Архитектура решения

### 1. Расширение модели Episode

```kotlin
data class Episode(
    val season: Int,
    val number: Int,
    val title: String?,
    val url: String,
    val releaseDate: String? = null,      // "2024-12-02"
    val status: EpisodeStatus = EpisodeStatus.UPCOMING
)

enum class EpisodeStatus {
    RELEASED,    // Вышла (серая или зеленая)
    CURRENT,     // Выходит сейчас (подсвечена)
    UPCOMING     // В ожидании (тусклая)
}

data class SeasonWithEpisodes(
    val seasonNumber: Int,
    val episodes: List<Episode>,
    val isExpanded: Boolean = false
)
```

### 2. Адаптер для отображения

**SeasonAdapter** (главный адаптер)
- Отображает сезоны как expandable элементы
- Каждый сезон может быть развернут/свернут
- Показывает количество эпизодов в сезоне

**EpisodeAdapter** (вложенный адаптер для эпизодов внутри сезона)
- Отображает эпизоды с номером, названием, датой
- Цветовая индикация по статусу
- Клик по эпизоду открывает плеер

## 🎨 Рекомендуемый Дизайн для Sloosh

**Стиль:** Современный, минималистичный, как у остального приложения

**Компоненты:**
1. **Сезон (заголовок раскрываемый)**
   - Иконка расширения (▼/▶)
   - "Сезон N" с названием (если есть)
   - Количество эпизодов
   - Плавная анимация открытия/закрытия

2. **Эпизод (элемент списка)**
   - Номер эпизода (1x01, 1x02)
   - Название эпизода (если есть)
   - Дата выхода (серая, маленький текст)
   - Статус индикатор (иконка + цвет)
   - Ripple эффект при клике

3. **Цветовая схема статусов:**
   - ✅ **Вышла**: зеленый + галочка (или серый если старая)
   - 🔴 **Выходит**: красный/оранжевый + точка (пульсирующая)
   - ⭕ **Ждёт**: серый + круг (тусклый)

## 🔍 Селекторы CSS для парсинга

Исходя из HDrezka-app анализа:

```css
/* Расписание */
div.b-post__schedule                    /* Контейнер всего расписания */
div.b-post__schedule_block              /* Блок одного сезона */
div.b-post__schedule_block_title        /* Заголовок сезона */
div.title                               /* Текст названия сезона */
div.b-post__schedule_list table tbody   /* Таблица с эпизодами */
table tbody tr                          /* Строка эпизода */
td                                      /* Ячейки (номер, дата, статус) */
```

**Пример парсинга:**
```kotlin
val seasonsElements: Elements = document.select("div.b-post__schedule div.b-post__schedule_block")
for (block in seasonsElements) {
    // Название сезона
    val header: String = block.select("div.b-post__schedule_block_title div.title").text()
    
    // Эпизоды
    val episodes: Elements = block.select("div.b-post__schedule_list table tbody tr")
    for (episodeEl in episodes) {
        val tds: Elements = episodeEl.select("td")
        if (tds.size >= 3) {
            val episodeNum = tds[0].text()      // "1 серия"
            val releaseDate = tds[1].text()     // "15 января 2024"
            val status = tds[2].text()          // "Вышла", "Выходит", "Ожидается"
        }
    }
}
```
