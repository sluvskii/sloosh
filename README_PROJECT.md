# Sloosh - Краткое резюме проекта

## 📱 Общая информация

**Наименование:** Sloosh  
**Описание:** Android приложение для просмотра фильмов и сериалов с источника данных HDRezka  
**Статус:** В разработке (v1.0)  
**Язык разработки:** Kotlin  
**Target platform:** Android 13+ (SDK 33-34)  

---

## 🎯 Основные возможности

### Пользователю
- ✅ Просмотр каталога фильмов и сериалов

## 🏗️ Архитектура на высоком уровне

```
UI Layer (Fragments, Compose)
```

## 🔑 Ключевые компоненты

### 1. HdRezkaApi (`data/hdrezka/HdRezkaApi.kt`)
- Сетевое взаимодействие с HDRezka
- Управление зеркалами с автоматическим failover
- Кеширование рабочих зеркал (6 часов TTL)
- Парсинг HTML контента с Jsoup
- Управление cookies и авторизацией

### 2. HdRezkaRepository (`data/repository/HdRezkaRepository.kt`)
- Координация между API и локальными источниками
- Фильтрация контента (фильмы, сериалы, мультфильмы, аниме)
- Управление кешем (bookmarks, episodes, watch-later)
- Поиск и фильтрация

### 3. ViewModels (`ui/*.kt`)
- **HomeViewModel**: Главная страница (новинки, популярное)
- **MoviesViewModel**: Управление списком фильмов
- **SeriesViewModel**: Управление списком сериалов
- Управление состоянием UI через StateFlow

### 4. Room Database (`data/AppDatabase.kt`)
- Таблицы: movies, watch_history, bookmarks
- DAO классы для работы с данными
- Локальное кеширование контента

### 5. LocalStorage (`data/LocalStorage.kt`)
- SharedPreferences обертка
- Сохранение cookies
- Пользовательские настройки
- Кеш последнего рабочего зеркала

## 🔐 Аутентификация и безопасность

### Процесс входа
1. Пользователь вводит учетные данные
2. Запрос отправляется на HDRezka
3. Cookies получены и сохранены в LocalStorage
4. Cookies автоматически добавляются к каждому запросу

### Безопасность
- SSL/TLS для всех соединений
- Автоматическое управление cookies
- Глобальный обработчик исключений с логированием
- Кеширование пользовательских данных локально

## 📊 Кеширование данных

### Multi-level Caching Strategy

```
Level 1: In-Memory (Maps)
  ├── bookmarksPageCache
  ├── membershipCache
  ├── watchLaterCache
  └── episodesCache
  
Level 2: Room Database
  ├── movies table
  ├── watch_history table
  └── bookmarks table
  
Level 3: SharedPreferences (LocalStorage)
  ├── Cookies
  ├── Last working mirror
  └── User preferences
```

### TTLs (Time To Live)
- Рабочее зеркало: 6 часов
- Кеш bookmarks: В памяти (сессия)
- История просмотров: В базе (постоянно)
- Cookies: До истечения срока
