## 🚀 Быстрый старт разработки

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd sloosh

# 2. Создать local.properties
echo sdk.dir=C:\\Users\\<YourUsername>\\AppData\\Local\\Android\\sdk >> local.properties

# 3. Открыть в Android Studio
# или собрать через Gradle

# 4. Debug сборка
./gradlew assembleDebug

# 5. Запуск на устройстве
./gradlew installDebug
```

## 💡 Ключевые моменты проекта

### Архитектура
- ✅ **MVVM** с StateFlow для reactive state management
- ✅ **Repository Pattern** для абстракции данных
- ✅ **Coroutines** для асинхронных операций
- ✅ **Jetpack Compose** для современного UI

### Особенности
- 🔄 **Mirror Failover** - автоматическое переключение между зеркалами
- 💾 **Multi-level Caching** - память, база данных, SharedPreferences
- 🍪 **Cookie Management** - автоматическое управление сессиями
- 🎬 **Media3 Player** - современный видеоплеер

### Готовность к production
- ✅ Обработка ошибок сети
- ✅ Логирование и crash reporting
- ✅ Lifecycle-aware компоненты
- ✅ Secure хранение данных
